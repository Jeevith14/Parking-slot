PROJECT INFORMATION

About ParkFlow

A simple and professional demonstration of a Stack data structure in a real-world parking application.

Project Objective

ParkFlow manages parking slots using the Stack (LIFO) principle. Available slots are stored in a stack. A new vehicle uses pop(), while an exited vehicle returns its slot using push().

Technology

HTML5 for structure, CSS3 for the responsive dashboard and JavaScript for the stack logic, UI updates and browser storage.
